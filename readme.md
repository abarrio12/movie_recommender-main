# 🎬 Movie Recommendation System

Recommends movies similar to the one you pick, using content-based filtering
(overview, genres, keywords, cast and director) on the TMDB 5000 dataset.
It is served with Flask and packaged with Docker.

As a bonus, the notebook includes **user-based collaborative filtering** and a
**hybrid recommender**, evaluated on the MovieLens dataset.

## Project structure

```
movie-recommender/
├── analysis.ipynb        # cleaning, model, evaluation and bonus; generates the .pkl files
├── app.py                # Flask app
├── model.pkl             # movies (id, title, year)          ← generated by the notebook
├── similarity.pkl        # similarity matrix (float32)       ← generated by the notebook
├── requirements.txt
├── Dockerfile
├── .dockerignore
├── templates/
│   └── index.html
└── data/
    ├── tmdb_5000_movies.csv
    ├── tmdb_5000_credits.csv
    └── ml-latest-small/  # MovieLens; downloaded automatically by the notebook
```

## How to run

### 1. Build the model

```bash
pip install -r requirements.txt
jupyter notebook analysis.ipynb     # run all cells
```

This creates `model.pkl` and `similarity.pkl`.

### 2. TMDB API key (for posters)

The app reads the key from the `TMDB_API_KEY` environment variable. If it isn't set, it
falls back to the key provided with the course template. You can create your own free key at
<https://www.themoviedb.org/settings/api>. If no key works, the app still runs but shows the
movies without posters.

### 3a. Locally

```bash
export TMDB_API_KEY="your_key"      # Windows PowerShell: $env:TMDB_API_KEY="your_key"
python app.py
```

### 3b. With Docker

```bash
docker build -t movie-recommender .
docker run -p 5000:5000 -e TMDB_API_KEY="your_key" movie-recommender
```

Then open <http://localhost:5000>.

## Results

**Content model**: TF-IDF with 5,000 terms. It was chosen over CountVectorizer because, when
evaluated against real MovieLens ratings, it recommends with more than twice the precision.

**Recommendations for MovieLens users** (precision@10 / recall@10 on the test set):

| Model                              | precision@10 | recall@10 |
|------------------------------------|-------------:|----------:|
| Popularity (baseline)              | 0.114        | 0.116     |
| Pure content                       | 0.024        | 0.037     |
| Collaborative (user-based, k=60)   | 0.127        | 0.135     |
| **Hybrid (α = 0.75)**              | **0.143**    | **0.157** |

Collaborative filtering also improves rating prediction: RMSE 0.89 vs 0.95 when predicting
each user's mean rating.

## Notes

- `similarity.pkl` is ~92 MB: GitHub accepts it (100 MB per-file limit) but shows a warning
  above 50 MB. If uploading it causes problems, use [Git LFS](https://git-lfs.com/).
- The `.pkl` files must be generated with the same pandas/numpy versions the app uses
  (those in `requirements.txt`); otherwise they may fail to load inside Docker.
